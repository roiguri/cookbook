# Global Invariants — Cookbook Native App (`apps/mobile`)

> Every P0 invariant has **100% pass requirement** across both Android and iOS. Failure on any P0 invariant automatically blocks convergence regardless of the aggregate satisfaction score.

## P0 Invariants (Hard Release Blockers)

| ID            | Category                               | Invariant Specification                                                                                                                                                                                                                                | Verification Source                                             |
| ------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| **INV-P0-01** | Auth & Roles                           | Unauthenticated guests can browse published recipes and view recipe details, but cannot mutate favorites, My Meal, private recipes, submissions, edit suggestions, Grandma's Cookbook, or Manager Dashboard.                                           | Firestore rules + Holdout Suite A                               |
| **INV-P0-02** | Role Escalation Prevention             | Signup ALWAYS creates `users/{uid}` with `role: 'user'`. A user or approved member can NEVER update their own `role`. Only a `manager` can change roles.                                                                                               | `firestore.rules` + Holdout Suite A                             |
| **INV-P0-03** | Private Recipe & Share Isolation       | Private recipes are visible ONLY to their author, managers, and explicitly shared `approved`/`manager` recipients. Revoking a share immediately revokes access. Recipients cannot edit or delete shared private recipes.                               | `firestore.rules` + `storage.rules` + Holdout Suite D           |
| **INV-P0-04** | Two-Tier Firebase Boundary             | Zero direct imports of `@react-native-firebase/*` or `src/services/_firebase/*` inside `app/**` or `src/components/**`. All Firebase access routes through domain services.                                                                            | ESLint rule + Reviewer Agent                                    |
| **INV-P0-05** | Storage `uploadedBy` & Size Compliance | Every client Storage upload includes `customMetadata: { uploadedBy: uid }`. Built avatars are PNG `< 200 KB` at `user-avatars/{uid}.png`.                                                                                                              | `storage.rules` + DTU snapshot audit + Holdout Suites F & G     |
| **INV-P0-06** | Zero PII in Sentry Observability       | `sendDefaultPii: false`. User context contains `{ id: uid }` ONLY (zero `email`, `fullName`, `displayName`, `avatarUrl`). Extra context contains IDs & op names ONLY (zero search queries, form inputs, recipe titles, or API tokens).                 | `logger.ts` + Telemetry audit + Holdout Suite L                 |
| **INV-P0-07** | Mandatory Submission Rejection Reason  | Managers CANNOT reject a pending submission with an empty/whitespace `rejectionReason`; UI disables/blocks submission and `firestore.rules` enforces `rejectionReason.size() > 0`.                                                                     | `firestore.rules` + Holdout Suite I                             |
| **INV-P0-08** | One-Time API Token Secret              | `createApiToken` reveals the raw plaintext token strictly once in the creation dialog; the client NEVER persists the plaintext token in Firestore, AsyncStorage, or Sentry logs.                                                                       | `functions/index.js` + Holdout Suite I                          |
| **INV-P0-09** | Cold-Start Hebrew RTL Fidelity         | Cold launch #1 on both Android and iOS renders RTL (`I18nManager.isRTL === true`) without needing an app restart. Zero LTR-flipped headers, cards, steppers, or drawers.                                                                               | Visual Multimodal Judge + RTL Hierarchy Audit + Holdout Suite L |
| **INV-P0-10** | Zero Fatal Native Crashes              | Zero unhandled JS exceptions, zero native crashes (`SIGABRT` / `AndroidRuntime` / iOS crash logs), and zero blank screens across all holdout scenarios.                                                                                                | Logcat / `os_log` / Sentry audit                                |
| **INV-P0-11** | Non-Production Isolation               | E2E builds target `com.roiguri.cookbook.e2e` + local DTU (`127.0.0.1`). Staging builds target `com.roiguri.cookbook.staging` + `cook-book-test-479e8`. Factory code NEVER references `my-cook-book-67fde` or merges to `development`/`staging`/`main`. | Static check + `verify-phase0.mjs`                              |
| **INV-P0-12** | Immutable Rules & Regression Lock      | `firestore.rules` and `storage.rules` are untouched by Builder Agents. Existing web `npm test`, `test:rules`, `test:functions`, `check:tokens`, `sync:shared`, and `npm run build` stay 100% green.                                                    | Orchestrator diff gate + Visible Gate                           |

## P1 Quality Invariants (Scored by Multimodal Judge — Target ≥ 95%)

- **INV-P1-01 (Design Token Adherence):** Warm cream surface ladder (`#faf6ec` → `#fffdf8` → `#f2e8cf`), primary green (`#6a994e`), secondary red (`#bc4749`), caution amber (`#b7791f`), proper Hebrew fonts (`Noto Sans Hebrew` / `Noto Serif Hebrew` + `Instrument Serif` / `Geist`), zero raw hex colors.
- **INV-P1-02 (Exact Serving & Fraction Math):** Scaling uses `@cookbook/core` `scaleIngredients` & `formatIngredientAmount` verbatim (`0.5` → `1/2`, `1.5` → `1 1/2`, near-integer snap `1/3 * 3` → `1`, bidi-safe LTR-isolated amounts inside RTL Hebrew rows).
- **INV-P1-03 (Offline Kitchen Resilience):** Native Firestore SQLite cache keeps previously viewed recipes, My Meal tabs, and ingredient checkoffs readable & interactive in airplane mode, syncing cleanly upon reconnect.
- **INV-P1-04 (Per-Platform Push Hygiene):** Opting in writes `users/{uid}/devices/{deviceId}` with exact `{ token, platform: 'android'|'ios', updatedAt }`; sign-out deletes that device doc.
- **INV-P1-05 (Cold Launch Performance):** Cold launch to first meaningful Hebrew content `< 3.5 s` on Android Emulator and iOS Simulator.
